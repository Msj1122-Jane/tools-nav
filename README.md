# 七瑾的工具台

从浏览器书签、课程资料与数据集清单整理出来的个人工具导航页，401 个站点，两级分类，鼠标悬停即显示每个工具的功能优势。

## 在线访问

GitHub Pages 地址见仓库 About 区域，或直接用 `https://<用户名>.github.io/tools-nav/`。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面本体，含样式、交互与分类树定义（`TREE` 常量） |
| `nav-data.js` | 数据文件，每行一个工具，日常增删改只碰这一个 |
| `nav-icons.js` | 站点图标（base64 内嵌，离线可显示），按 url 自动匹配，一般不用改 |

## 怎么改

**改一个工具**：编辑 `nav-data.js`，找到那一行改字段即可，刷新页面生效。

```js
{"cat":"AI 生成","sub":"AI 绘画","tag":"AI绘画","name":"Midjourney","tip":"功能优势一句话","desc":"原始名称","url":"https://...","host":"midjourney.com","add":1690000000}
```

字段含义：`cat` 大类 · `sub` 二级 · `tag` 关键词 · `name` 显示名 · `tip` 悬停显示的功能优势 · `desc` 备用名与搜索用 · `url` 链接 · `host` 域名 · `add` 添加时间戳。

**加一个工具**：复制任意一行改字段；或在页面右上角「＋ 添加」随手加（存在浏览器本地，可用「导出」存成书签 HTML）。

**改分类名或顺序**：编辑 `index.html` 顶部的 `TREE` 常量，同步改 `nav-data.js` 里对应的 `cat` / `sub`。

## 页面功能

- 左侧两级分类树，可折叠，展开状态会记住
- 搜索支持站名、域名、功能优势、标签模糊匹配，按 `/` 聚焦
- 悬停任意卡片浮出功能优势说明
- 收藏（☆）置顶，存在浏览器本地
- 卡片 / 列表两种视图，深浅两套主题
- 导出为标准书签 HTML，可重新导回浏览器
- 窗口窄于 1000px 时侧栏收成抽屉
